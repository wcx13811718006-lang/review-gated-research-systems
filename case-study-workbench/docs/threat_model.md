# Threat Model

## Main risks

- Overclaiming planned or funded work as completed or operational.
- Treating modeled benefits or portfolio metrics as measured local outcomes.
- Overriding Tribal/Nation-authored public wording with supporting sources.
- Publishing sensitive cultural, relocation, health, safety, or engineering
  material before review.
- Letting dynamic weather/smoke context change approved case claims.
- Losing provenance when source pages change or disappear.

## Controls

- Claim-level ledger with source IDs and locators.
- Conservative claim-boundary classifier.
- Mandatory review routes for high-risk content.
- Export gate that blocks missing claim IDs, unresolved review, missing rights,
  and source failures.
- Source snapshots with hash, timestamp, and access status.
- Static seasonal fallback for public prototype.

## Out of scope

This system must not provide emergency guidance, health advice, safety
instructions, or real-time operational decisions.
