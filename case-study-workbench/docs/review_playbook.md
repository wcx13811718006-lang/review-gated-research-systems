# Review Playbook

## Mandatory full review

Required for Tribal/Nation-led cases, cultural knowledge, data sovereignty,
relocation, public health/smoke, fisheries, wetlands, hydrology, flooding,
sea-level rise, engineering, legal/safety, and measured outcome claims.

## Targeted review

Required when the system detects conflicting status/date, missing project lead,
broad portfolio scope, uncertain geography, unclear source owner, or substantive
source diffs.

## Random audit

Allowed only for low-risk metadata such as source owner, URL, basic geography,
title, and broad hazard tag. Early pilots should keep a high audit fraction until
precision is proven.

## Blocked export

Any of the following blocks export:

- missing primary source
- missing claim-source mapping
- unsupported measured outcome
- unresolved mandatory review
- missing rights, caption, credit, or alt text
- stale or failed required source
- unresolved Tribal/Nation public-use boundary
